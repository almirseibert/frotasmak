# Post de divulgação — grupos de WhatsApp das obras

> Texto pronto para copiar e colar. **Enviar apenas nos grupos das obras já habilitadas** —
> a mensagem afirma que a obra que a recebeu já pode pedir com liberação automática.
>
> Para conferir quais obras estão habilitadas: Admin → Frota → Aceite Automático → "Obras participantes".

---

## Versão principal

```
⛽ *ABASTECIMENTO MAIS RÁPIDO — SUA OBRA JÁ ESTÁ NO NOVO SISTEMA*

A partir de agora, o pedido de abastecimento feito pelo site sai *na hora*, sem esperar alguém liberar.

*Como pedir:*
1️⃣ Acesse *frotamak.com* pelo celular
2️⃣ Preencha o pedido (veículo, posto, combustível)
3️⃣ Tire a foto do painel mostrando o km ou as horas
4️⃣ Envie

Se estiver tudo certo, a *ordem é liberada automaticamente* e vai direto para o posto. Você recebe o aviso aqui no WhatsApp. ✅

*Para a liberação sair na hora:*
📸 Foto do painel *nítida* e com os números legíveis
🔢 Digite o km/horas *exatamente* como está no painel
🚛 Confira se escolheu o *veículo certo*

Se algo não bater, o pedido segue normalmente para o setor de abastecimento conferir — como sempre foi. Nada se perde.

🧾 *Depois de abastecer:* mande a foto do cupom pelo site, no mesmo pedido. Isso encerra a ordem.

📌 As obras e veículos estão entrando aos poucos no novo sistema. *A sua obra já está liberada.*

Dúvidas? Fale com o setor de Abastecimento.
```

## Versão curta (para grupos movimentados)

```
⛽ *NOVIDADE — SUA OBRA JÁ ESTÁ LIBERADA*

Pedido de abastecimento pelo *frotamak.com* agora sai *na hora*, sem esperar liberação.

Basta preencher o pedido e mandar a *foto do painel bem nítida*, com o km/horas legível. Estando tudo certo, a ordem vai direto para o posto e você recebe o aviso aqui. ✅

Se algo não bater, o pedido vai para o setor conferir, como sempre. Nada se perde.

🧾 Depois de abastecer, mande a foto do cupom pelo site.

📌 As obras estão entrando aos poucos — *a sua já está no novo sistema.*
```

---

## Observações para quem for enviar

**O que a mensagem promete, e o que não promete.** Ela diz que o pedido *pode* sair na hora quando
está tudo certo, não que *sempre* sairá. Isso é proposital: se prometermos liberação sempre imediata
e o pedido cair na conferência humana, o operador vai achar que o sistema falhou e voltar a ligar
para o setor — que é justamente o que queremos evitar.

**Não enviar em grupo de obra ainda não habilitada.** O texto afirma que a obra que recebeu já está
liberada. Mandar no grupo errado gera pedido que cai na fila manual e a sensação de que "não
funcionou".

**Antes de enviar, confirme:**

- [ ] A obra está marcada em Admin → Frota → Aceite Automático → Obras participantes
- [ ] O modo está em **ativo** (em modo sombra nada é liberado automaticamente — não divulgue ainda)
- [ ] Os veículos da obra têm capacidade de tanque e média cadastradas

**Se ainda estiver em modo sombra**, não envie nenhuma das versões acima. Nessa fase o sistema está
apenas medindo, e nenhuma ordem sai automaticamente — a mensagem estaria prometendo algo que ainda
não acontece.

## Mensagem automática que o operador recebe

Quando a ordem é liberada automaticamente, o sistema já manda no WhatsApp de quem pediu:

```
✅ *Abastecimento Liberado*

Sua solicitação para o veículo *RE 123 – ABC1D23* foi liberada automaticamente.

*Ordem Nº 16950* já foi enviada ao posto.

Após abastecer, envie a foto do cupom pelo app.
```

Não é preciso avisar manualmente quem pediu.
